# THE HARSH EDITOR — Portfolio & Digital Experience Studio

> An award-winning, interactive 3D portfolio website inspired by [Lusion.co](https://lusion.co/). Built with React, TypeScript, Three.js / React Three Fiber, GLSL Shaders, Framer Motion, and Tailwind CSS.

---

## ✨ Features

- **Fluid 3D WebGL Liquid Blob**: Custom GLSL vertex displacement and chromatic dispersion shader reacting to mouse movement and scroll trajectory.
- **Micro-Interactions & Synthesized Web Audio**: Interactive procedural audio feedback on hover, clicks, and transitions.
- **Showreel Player**: Ultra-crisp modal video player with custom controls, time scrubbers, and sound wave animations.
- **Dynamic Visitor Analytics & Review Hub**: Live viewer simulation counter, real-time client testimonial reviews with interactive rating submissions.
- **Specialized Editing Arsenal**: Tailored showcase for YouTube long-form, viral Reels/Shorts, DaVinci Resolve color grading, and generative AI B-roll pipelines.
- **Responsive & High-Performance**: 60fps GPU acceleration across Desktop, Tablet, and Mobile with dark obsidian aesthetics.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **3D & Graphics**: [Three.js](https://threejs.org/) + [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) + [@react-three/drei](https://github.com/pmndrs/drei) + Custom GLSL Shaders
- **Animations**: [Framer Motion](https://www.framer.com/motion/) + [Lenis Smooth Scroll](https://github.com/darkroomengineering/lenis)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

---

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel (1-Click)

1. Push your code to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import your `harsh-portfoliyo` repository.
4. Framework Preset will automatically detect **Vite**.
5. Click **Deploy**!
